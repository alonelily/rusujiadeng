# 如数迦贞 PC 端

PC 端是独立的静态网页版本，与 Android、iOS 的原生工程分开维护。它会在浏览器本地保存剧情作品，不需要账号或服务器。

## 启动

请在 `pc-app` 目录执行：

```powershell
python -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。也可以使用 VS Code Live Server 等本地静态服务器。

不要直接双击 `index.html`，否则部分字体、视频模块和浏览器存储能力可能受 `file://` 限制。

## 本地作品

剧情作品、生成差分和本地 BGM 默认保存在当前浏览器的 IndexedDB 中。换浏览器或清除网站数据前，请在剧情生成器中使用“备份”导出 `.rusu` 文件。
